Подключение Firebase для работы всего класса

Создайте Firebase Project → Realtime Database → Web App. Вставьте конфигурацию Web App и адрес базы. Для реального использования настройте аутентификацию и правила доступа: общедоступная база с данными учеников небезопасна.

В этой версии подключение предназначено для тестового проекта с настроенными правилами. Не загружайте реальные ФИО учеников в публичную базу. Для школьного использования нужен отдельный защищённый вход для учителя и учеников.
